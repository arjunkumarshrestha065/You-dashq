# YouDash branding

- **Project name:** YouDash (one word, capital Y and D).
- **Descriptor:** Native YouTube for Apple CarPlay.
- **Canonical repository:** https://github.com/sa4hnd/YouDash
- **Short description:** Native YouTube on Apple CarPlay, with YouMod ad blocking and responsive layouts.
- **Mark:** `assets/youdash-mark.svg`, an original dashboard/play symbol. Preserve its square proportions.
- **Palette:** near-black `#0f0f0f`, white `#ffffff`, accent red `#ff0033`.

Keep “YouTube” and “Apple CarPlay” prominent in page titles, introductions, repository topics, and screenshot descriptions so readers can identify the project. Keep technical names such as `YouTubeCarPlay.dylib`, existing runtime classes, bundle IDs, and old release asset filenames compatible.

The name was selected after an initial web search identified unrelated existing uses, including a delivery app and a YouTube recommendation project. The owner chose to proceed with the distinct CarPlay descriptor. This is not a claim that the name is exclusive or trademark-cleared.

YouDash is independent of Google and Apple. Preserve YouMod attribution and the source/binary licensing distinction. Do not claim universal compatibility, official endorsement, or guaranteed playback/ad blocking.
