# Security and privacy

Do not post credentials, signing keys, profiles, device identifiers, media URLs, account information, or raw app-container exports in issues. Review every diagnostic file before sharing.

For a sensitive finding, use GitHub's private vulnerability-reporting feature when available; otherwise contact the repository owner privately through GitHub. Never open a public issue containing a secret.

The project does not provide signing certificates, shared Apple accounts, authentication tokens, or missing entitlements. Build artifacts intended for sharing must be unsigned and profile-free. See `docs/RELEASING.md` for the audit procedure.
